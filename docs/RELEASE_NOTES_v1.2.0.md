# 挪车提醒 v1.2.0

Android 违停短信提醒工具：轻提醒 → 震动 → 闹钟，全程本地运行，不申请联网权限。

## 本次更新

- 新增自启动 / 后台弹出手动确认流程。
- 新增每天 **09:00 / 18:00** 权限检查；缺失时通知提醒。
- 每日检查时会尝试重新启动后台守护服务。
- 常驻通知标题改为“挪车提醒守卫中”。
- 关闭后台守护后，首页切换为棕褐色“守卫已关闭”状态，不再显示“守卫中”。
- 新增 4 个权限检查时间计算测试，总测试数 15。

## 安装包

- 文件：`ParkingAlert-v1.2.0.apk`

## 首次使用

1. 允许短信读取、通知权限。
2. 开启精确闹钟、全屏提醒。
3. 加入电池优化白名单。
4. 小米/华为/OPPO/vivo 等机型允许自启动、后台弹出、锁屏显示；返回 App 后点“已开启”。
5. 打开 App，点“测试一次提醒”。

> 本 APK 为个人侧载版本，不通过 Google Play 分发。请先在自己的手机上测试短信接收和闹钟链路。
