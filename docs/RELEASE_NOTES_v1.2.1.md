# 挪车提醒 v1.2.1

Android 违停短信提醒工具：轻提醒 → 震动 → 闹钟，全程本地运行，不申请联网权限。

## 本次更新

- 顶部副标题由“停车短信守卫”改为“**挪车短信守卫**”。
- “后台守护”统一改名为“**后台常驻**”，避免误以为它控制短信监听。
- 关闭状态标题改为“**后台常驻已关闭**”。
- 关闭状态副标题改为更通俗的说明：
  “短信还能收到，但手机可能清理后台，提醒会变慢或漏掉。”
- 开启状态副标题改为“短信正常监听，后台常驻中”。

## 安装包

- 文件：`ParkingAlert-v1.2.1.apk`
- 版本：1.2.1（versionCode 5）
- 最低系统：Android 8.0（API 26）
- SHA-256：`D0181924EA032FF8033D3989185FBD6B4D731067FAC3106AEAB1ACA724D1A5BC`

## 首次使用

1. 允许短信读取、通知权限。
2. 开启精确闹钟、全屏提醒。
3. 加入电池优化白名单。
4. 小米/华为/OPPO/vivo 等机型允许自启动、后台弹出、锁屏显示；返回 App 后点“已开启”。
5. 打开 App，点“测试一次提醒”。

> 本 APK 为个人侧载版本，不通过 Google Play 分发。请先在自己的手机上测试短信接收和闹钟链路。
