# 挪车提醒 v1.1.1

Android 违停短信提醒工具：轻提醒 → 震动 → 闹钟，全程本地运行，不申请联网权限。

## 本次更新

- 首页状态改为“守卫中”，副标题统一为“停车短信守卫”。
- 图标与 App 配色统一为青绿、白色和琥珀色。
- 首页权限区域只显示未开启项，全部开启后自动隐藏。
- 三段式提醒保持：轻提醒 → 60 秒 → 震动 → 60 秒 → 全屏闹钟。
- 新增正式 README、MIT License。

## 安装包

- 文件：`ParkingAlert-v1.1.1.apk`
- 版本：1.1.1（versionCode 3）
- 最低系统：Android 8.0（API 26）
- SHA-256：`25DA031884F7E1FBE2B98CED01D4446D48D15863D1AF50F151177F7F7D5F34D6`

## 首次使用

1. 允许短信读取、通知权限。
2. 开启精确闹钟、全屏提醒。
3. 加入电池优化白名单。
4. 小米/华为/OPPO/vivo 等机型允许自启动、后台弹出、锁屏显示。
5. 打开 App，点“测试一次提醒”。

> 本 APK 为个人侧载版本，不通过 Google Play 分发。请先在自己的手机上测试短信接收和闹钟链路。
